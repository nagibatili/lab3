# FoodCampus — MenuModule (практическая работа)

Учебный проект: реализация программного модуля **MenuModule** по User Story и утверждённой архитектуре.

> **User Story:** «Как повар, я хочу фильтровать блюда по категориям, чтобы выдавать актуальное меню».
> **Интерфейс от архитектора:** `get_filtered_menu(category, only_available)`
> **Зона ответственности:** хранение списка блюд, фильтрация по типу (суп, второе) и наличию.

## Файлы проекта

| Файл | Что это |
|---|---|
| `menu.py` | Код модуля MenuModule (итоговая, исправленная версия) |
| `test_menu.py` | Автоматические тесты (стандартный `unittest`, 42 теста) |
| `test_runner.py` | Тестовый драйвер-сценарий: печатает результаты позитивных и негативных тестов на экран |
| `bug_report.md` | Отчёт о найденных дефектах (4 реально воспроизведённых бага: BUG-01…BUG-04) |
| `report.md` | Отчёт о проделанной работе |

## Требования

- Python 3 (проверено на Python 3.11.9).
- Сторонние библиотеки НЕ нужны — использованы только стандартные модули.

## Как запустить

Все команды выполняются из папки проекта.

**1. Автоматические тесты:**

```
python -m unittest test_menu.py -v
```

Ожидаемый результат: `Ran 42 tests in 0.002s` и строка `OK`.

**2. Демонстрационный прогон сценариев (как в примере из задания):**

```
python -X utf8 test_runner.py
```

Ожидаемый результат: позитивные сценарии с результатами, 12 негативных сценариев со строками `[OK] ... -> ValueError: ...`, в конце — «Все позитивные assert-проверки прошли успешно».

> Примечание для Windows: флаг `-X utf8` нужен, чтобы русский текст выводился без «кракозябр». На системах с кодировкой UTF-8 по умолчанию достаточно `python test_runner.py`.

## Что должен уметь модуль (обязанности по User Story)

- хранить список блюд (`add_dish`, `get_all_dishes`);
- фильтровать по категории: `menu.get_filtered_menu("суп", False)`;
- фильтровать по наличию: `menu.get_filtered_menu("суп", True)`;
- применять оба фильтра одновременно;
- корректно вести себя на пустом меню и при отсутствии результатов;
- отклонять некорректные данные (не-строка категория, отрицательная цена, блюдо без обязательных полей и т.п.) с понятным сообщением вместо падения программы.

## Быстрая проверка руками (3 минуты)

```python
from menu import MenuModule

menu = MenuModule()
menu.add_dish({"name": "Борщ", "category": "суп", "price": 120.0, "available": True})
menu.add_dish({"name": "Щи", "category": "суп", "price": 100.0, "available": False})

print(menu.get_filtered_menu("суп", True))   # [{'name': 'Борщ', ...}] — только доступный борщ
menu.add_dish({"name": "Каша", "price": -50, "available": True})
# ValueError: в блюде нет обязательных полей: category
```
